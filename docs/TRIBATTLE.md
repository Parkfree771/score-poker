> 시뮬 코드: 세션 스크래치의 `tribattle_sim3.py` (필요 시 tool/로 이관).

## 0. 한 줄 요약

물·불·숲 카드를 **상대와 뺏고 뺏기며 드래프트**해 3×5 격자에 놓고,
행·열 조합으로 8개 전선에서 싸워 상대 HP를 깎는 1:1 전략 카드 배틀.

## 1. 왜 이 게임인가 (설계 동기)

가림 룰 실플레이 결론: 내 패에만 집중하게 되고 상대를 볼 이유가 없다(레이스 구조).
트라이 배틀은 상대를 보는 행위 자체에 세 가지 보상을 건다:
드래프트 견제(뺏기) · 열 대결 카운터(상성) · 상대 잭팟 저지(마켓 끊기).

## 2. 구성

| 항목 | 값 |
|---|---|
| 덱 | 물💧·불🔥·숲🌳 × 랭크 1~9 × 3벌 = **81장** (조커 2장은 튜닝 서랍 §8) |
| 보드 | 각자 3행 × 5열 = 15칸 |
| HP | 각자 **60** |
| 매치 | 판(격자 완성)을 반복, 진 쪽만 (승자−패자 데미지)만큼 HP 감소, 0이면 패배 |

## 3. 판의 진행 — 3라운드 드래프트

라운드마다:

1. 덱에서 **11장을 마켓에 공개**
2. **직전 정산에서 이긴 쪽부터** `1-2-2-2-2-1` 순서로 픽 (선1 후2 선2 후2 선2 후1)
   — 픽한 카드는 **그 자리에서 즉시 배치**한다(상대에게 보인다). 남은 1장 소각
3. 라운드가 끝나면 중간 정산(§5) — 다음 라운드 선픽 결정

1인당 5장 × 3라운드 = 15장 = 보드 완성. 합성(§4)으로 칸이 비면 그만큼 빈 칸이 남을
수 있다 — 빈 칸은 점수 0이므로 합성은 공간 대비 가치를 스스로 증명해야 한다.

## 4. 배치와 합성

- 배치: 빈 칸, 또는 **같은 숫자** 위에 겹치기(=합성)
- 합성값 = (두 값의 합) × 2. 예: 3+3 → 12, 12+12 → 48
- **원소는 이기는 쪽이 남는다**: 물은 불을 끄고, 불은 숲을 태우고, 숲은 물을 마신다
  ```
  물3+물3 → 물12    물3+불3 → 물12    불3+숲3 → 불12    숲3+물3 → 숲12
  ```
  같은 원소 합성은 생각 없이 안전, 교차 합성은 삼각형을 읽어야 한다.
  → 원소 변환 기술: 물 줄에 물이 부족하면 불 카드를 물에 합성해 물로 바꾼다.

## 5. 점수와 전선

**조합 점수 = 랭크 합 × 배율** (조합은 숫자만 만든다 — 원소는 배율만)

| 배율 | 행(5칸) | 열(3칸) |
|---|---|---|
| 페어 | ×2 | ×2.5 |
| 트리플 | ×3 | ×5 |
| 3스트레이트 | ×3 | ×4 |
| 5스트레이트 | ×5 | — |
| 포카드 | ×5 | — |
| 파이브 | ×8 | — |

**순수(단일 원소) 배율 — 줄이 가득 찼을 때만**:
열 3장 전부 ×1.25 · 행 5장 중 4장 ×1.25 · 행 5장 전부 ×1.5

**전선 8개**: 내 열i vs 상대 열i (5개) + 내 행i vs 상대 행i (3개).
열 대결에서 내 주원소(다수결)가 상대 주원소를 상성으로 이기면 내 점수 ×1.5.

**데미지 = 전선별 점수차를 상한으로 잘라 합산**:

| 전선 | 상한 |
|---|---|
| 열 | 10 |
| 행 | 20 |
| 행이 **포카드**면 | 60 (=×3) ← 잭팟 |
| 행이 **파이브**면 | **무제한** ← 대잭팟 |

상한 덕에 몰빵은 초과분이 낭비돼 자멸하고(시뮬 §7), 잭팟 행만이 상한을 뚫는다 —
합성으로 같은 값을 모아 포카드 행을 만드는 것이 역전 플랜이다.

## 6. 확정 원칙 (흔들리면 여기로 돌아올 것)

1. **숫자가 조합을 만들고, 원소는 배율만 만든다.** 원소 조합표(물+불=증기 따위)는
   만들지 않는다 — 암기 부담과 밸런스 부채의 원천.
2. **페널티보다 보너스.** 섞임 감점 없음 — 순수 보너스를 놓치는 것이 이미 대가다.
3. **계산은 게임이 하고 플레이어는 비교만 한다.** 배치 후보 칸마다 획득 점수를
   미리 보여주는 UI가 전제다(2048·발라트로 문법).
4. 상성 레이어는 원소 하나뿐. 조합 간 상성(스트레이트>트리플 따위)은 넣지 않는다.

## 7. 시뮬레이션 근거 (자가대전, 300~600판/매치업)

| 검증 항목 | 결과 |
|---|---|
| 전략성 | 무작위 플레이 승률 0~1% |
| 양축 강제 | 행만 보는 전략 15%, 열만 12% — 한 축 포기 = 자멸 |
| 몰빵 견제 | 한 열 몰빵 24~32% (상한 없이도 자멸 — 상한은 보험) |
| 선픽 공정성 | 1라운드 선픽 쪽 승률 **48%** (스네이크+이긴쪽선픽 조합) |
| 잭팟 빈도 | 포카드+ 행 0.36회/판 (≈3판에 1번) — 1~9 랭크 덱이 1~13 덱(0.13)보다 3배 |
| 순수 빈도 | 열 1.2개/판, 행 5장 0.14개/판 → 4장 단계 인정으로 보완 |
| 판당 순데미지 | 중앙값 23 (잭팟 판 46) → HP 60 = 매치 중앙값 3판, 최장 ~6판 |
| 합성 | 4~5회/판, 합성 추구 전략 승률 37~44% (성립하는 서브 플랜) |

## 8. 튜닝 서랍 (프로토타입에서 손맛 보고 결정)

- 조커 2장(원소·랭크 와일드) 투입 — 잭팟 빈도 상향 레버
- 행:열 데미지 기여 62:38 → 열 상한 10→12 또는 열 배율 미세 상향으로 55:45 목표
- 순수 배율 1.25/1.5 스윕 · 합성 배율 ×2 고정 여부
- 원소 패시브(물=흐름/불=폭발/숲=굳건) — 코어 안착 후 1.1에서 실험
- 숨김(비공개 픽) 요소 — 드래프트 수싸움으로 부족할 때만
