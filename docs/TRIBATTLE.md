## 0. 한 줄 요약

매 턴 카드를 **비공개로 1장 뽑아** 내 전장(3열×5칸)에 쌓거나, 상대 필드의 **같은 숫자를
공격**해 날려버리는 1:1 배틀. 코인으로 카드를 **숨기고**, 상대 카드를 **훔쳐본다**.

## 1. 구성

| 항목 | 값 |
|---|---|
| 덱 | 물💧·불🔥·숲🌳 × 랭크 1~9 × 3벌 = **81장** |
| 전장 | 각자 **3열**, 열마다 5칸 — **아래(1행)부터** 채운다 |
| 시작 | 손패 **2장**, 코인 **5개** |
| 코인 수입 | 내 턴 3번마다 +1 |
| HP | 각자 **250** — 판을 반복, 진 쪽이 점수차만큼 깎인다 |

## 2. 턴 진행

1. 덱에서 1장 **비공개 드로** (손패에 합류 — 손은 계속 3장 유지)
2. 본 행동 하나:
   - **배치**: 손패 1장을 내 열의 다음 칸에. 앞면 무료 / **뒷면 = 코인 1**
     (뒷면 카드는 상대에게 안 보이고 **공격받지 않는다**)
   - **공격**: 손패의 랭크 = 상대 필드의 **보이는** 카드 랭크면 그 카드를 지목 —
     **두 장 모두 소멸**(위 카드는 아래로 떨어짐). 공격자는 보충 1장을 뽑는데
     이것이 **방어막 카드**다(아래 §3)
   - **버리기**: 내 전장이 만석일 때만
3. 덤 행동(턴 소모 없음): **훔쳐보기 = 코인 1** — 상대 뒷면 카드 1장을 나만 확인.
   본 카드는 이후 내가 공격할 수 있다

## 3. 방어막 카드 (공격의 보상이자 무기)

공격 성공 보충 카드는 **공격 불가·피격 불가**. 대신 **양쪽 필드 아무 유효 칸**에 놓을 수
있다 — 내 빈칸을 안전하게 채우거나, **상대 열에 낮은 숫자를 꽂아 조합을 망친다**.
방어막이라 상대는 그걸 제거할 방법이 없다. 시뮬 결과 이 선택이 승률을 가장 크게 가르는
스킬 포인트다(§7).

## 4. 정산 (양 보드 완성 또는 덱 소진)

**점수 = 줄마다 랭크 합 × 조합 배율**, 총점 비교 → 진 쪽 HP −점수차.

| 열(5칸) 조합 | 배율 | | 행(3칸) 조합 | 배율 |
|---|---|---|---|---|
| 페어 | ×2 | | 페어 | ×2 |
| 3연속 | ×2.5 | | 3연속 | ×3.5 |
| 트리플 | ×3 | | 트리플 | ×5 |
| 풀하우스 | ×5 | | | |
| 포카드 | ×6 | | | |
| 5연속 | ×7 | | | |
| 파이브 | ×10 | | | |

**플러시(원소 통일, 줄 만석 시)**: 열 ×2 (11판에 1번꼴 레어) · 행 ×1.3 (판당 1번꼴).

## 5. 확정 원칙

1. **공격 매칭은 랭크만** — 원소는 플러시(배율)와 연출에만 관여. 원소 조합표 금지.
2. **큰 조합은 공격 표적이다** — 같은 랭크를 모을수록 노출. 지키려면 코인으로 숨겨라.
   조합 욕심 ↔ 코인 소모 ↔ 정보 노출이 한 고리다.
3. **계산은 게임이 하고 플레이어는 비교만 한다** — 배치 +점수 미리보기, 공격 가능
   표적 하이라이트, 열 배지 우세 색이 UI 전제.
4. 방어막 딜레마(내 필드 vs 상대 견제)는 UI가 양쪽 다 크게 보여준다.

## 6. 왜 이 게임인가

- **주고받는 재미**: 판당 공격 ~14회 (4턴에 1번꼴) — 그러나 "기회마다 무조건 공격"은
  가치 선별 공격에게 41:59로 진다. 공격은 스팸이 아니라 판단.
- **만드는 재미**: 페어~파이브 달성률이 희귀도 사다리를 이룬다(§7 표).
- **운의 재미**: 뽑고 바로 결정 + 덱 카운팅(81장 고정, 상대가 뭘 집었는지 절반은 보인다).
- **칩의 재미**: 뒷면 ~11회/판이 공격 기회 ~16회를 차단 — 코인 수요(16) > 공급(12).

## 7. 시뮬레이션 근거 (400~500판/조건, 스마트 봇 자가대전)

| 검증 항목 | 결과 |
|---|---|
| 판 길이 | 중앙값 46턴(1인 23턴), 100% 정상 종료 |
| 공격 빈도 | 14.4회/판 — 시작 패 0~5장 사이 13~15로 둔감(패 2 확정은 선택지 확보용) |
| 공격 스팸 견제 | 무조건 공격 41% vs 가치 공격 59% |
| 방어막 스킬 갭 | 상황 판단형 71% vs 무조건 자기 필드 29% — 최대 스킬 포인트 |
| 스킬 갭(종합) | 스마트 봇 vs 근시안 봇 62~68% |
| 선후공 | 미러전 47:53 — 공정 범위 |
| 조합 달성(판당) | 열페어 2.2 · 열트리플 1.2 · 풀하우스 0.39 · 포카드 0.35 · 5연속 0.09 · 열플러시 0.06 · 파이브 0.02 |
| 점수차 | 중앙값 ~105 → HP 250 = 매치 2~4판 |

## 8. 튜닝 서랍
