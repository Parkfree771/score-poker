# 트라이 배틀 (Tri-Battle) — 룰 정본 v2.0

> 2026-08-28 확정. v1(3×5 이중축 격자)은 프로토타입 플레이 후 폐기 —
> "필드에 카드가 쌓이며 싸우는" 감각이 아니었다. v2는 **한 줄 누적 전장**.
> 모든 수치는 자가대전 시뮬레이션(§6)으로 검증. 시뮬: 세션 스크래치 `tribattle_sim4.py`.

## 0. 한 줄 요약

물·불·숲 카드를 상대와 뺏고 뺏기며 드래프트해 **5열 한 줄에 겹쳐 쌓고**(합체),
라운드마다 **열 대결 5번 + 족보 대결 1번**으로 상대 HP를 깎는 1:1 배틀.

## 1. 구성

| 항목 | 값 |
|---|---|
| 덱 | 물💧·불🔥·숲🌳 × 랭크 1~9 × 3벌 = **81장** |
| 전장 | 각자 **열 5개 한 줄** (정면 대치) |
| HP | 각자 **250** — 다 달 때까지. 별도 판/최종전 없음 |
| 라운드 | 최대 7 (덱 81 ÷ 마켓 11). 덱이 마르면 남은 HP 승 |

## 2. 라운드 진행

1. 마켓 **11장 공개** (가운데 공유)
2. **직전 라운드에 덜 맞은 쪽부터** `1-2-2-2-2-1` 스네이크 픽 — 픽 즉시 배치(공개),
   남은 1장 소각
3. 라운드 안에서 **각 열에 정확히 1장씩** (총 5장)
4. **2라운드부터 배치는 곧 합체(표롱)**:
   ```
   값 = 그냥 합             5물 + 6불 = 11물
   원소 = 이기는 쪽이 남는다   물은 불을 끄고, 불은 숲을 태우고, 숲은 물을 마신다
   ```
   → 열은 게임 내내 자라는 내 유닛이다. 원소 변환 기술: 물 열을 유지하고 싶으면
   불 카드를 얹어도 물이 남지만, 숲을 얹으면 숲이 되어버린다 — 삼각형을 읽어야 한다.

## 3. 라운드 정산 (양쪽 5칸이 다 차면)

**열 대결 ×5** — 유효값 = 값 × (상성이면 1.5). 진 열의 주인이 **차이만큼** HP를 잃는다.
이긴 쪽 원소의 공격 모션이 나간다(물색/불색/숲색 탄).

**족보 대결 ×1** — 5개 누적값의 족보 점수 = 값 합 × 배율:

| 족보 | 배율 |
|---|---|
| 하이 | ×1 |
| 원페어 | ×2 |
| 투페어 | ×2.5 |
| 트리플 | ×3 |
| 스트레이트 | ×4 |
| 플러시 (5열 원소 통일) | ×5 |
| 풀하우스 | ×6 |
| 포카드 | ×8 |
| 파이브 | ×10 |
| 스트레이트 플러시 | ×12 |

진 쪽이 점수 **차이만큼** HP를 잃는다. 합체값(10 이상)도 족보에 그대로 낀다 —
"두 열을 똑같이 20으로 키워 페어"가 이 게임의 크래프팅이다.
상한은 없다: 라운드가 갈수록 값이 커져 판돈이 자연히 상승한다(30→257, §6).

정산이 끝나면 덜 맞은 쪽이 다음 라운드 선픽.

## 4. 확정 원칙

1. **숫자가 족보를 만들고, 원소는 배율·상성만 만든다.** 원소 조합표는 만들지 않는다.
2. **합체는 이기는 원소가 남는다** — 상성 삼각형이 곧 합체 규칙(암기 불필요).
3. **계산은 게임이 하고 플레이어는 비교만 한다** — 합체 미리보기(얹으면 이 값·이 원소),
   열별 우세 화살표, 실시간 족보 라벨이 UI 전제다.
4. 페널티보다 보너스. 상한·감점 대신 자연 스케일링.

## 5. 연출 우선순위 (이 게임의 손맛)

1. **표롱(합체)**: 카드가 열로 날아가 얹히며 값 카운트업 + 팝
2. **원소 공격**: 이긴 열 → 진 열로 원소색 탄 + 명중 플래시 + 데미지 플로트
3. **족보 배너**: "풀하우스 612 vs 플러시 487" → 큰 한 방

## 6. 시뮬레이션 근거 (400판/조건)

| 항목 | 결과 |
|---|---|
| 라운드별 총데미지 중앙값 | R1 30 → R3 102 → R5 178 → R7 257 (자연 상승) |
| HP 250 게임 길이 | 중앙값 4라운드, 90% 6 (덱 한도 7 안) |
| 전략성 | 무작위 플레이 승률 0~2% |
| 스타일 다양성 | 족보 중심 vs 열 대결 중심 = 50:50 (둘 다 유효) |
| 선픽 유불리 | 미러전 50% — 공정 |

## 7. 튜닝 서랍

- 조커 2장(원소·랭크 와일드) — 족보 완성 드라마 레버
- HP 250 (150=속전 / 400=장기전) — 실플레이 감으로
- 열 대결 상성 1.5 스윕
- 봇 성격화: 페르소나 3인 = 물(크로드)·불(헷)·숲(제나) 원소 마스터
- 오늘의 시드(날짜 시드 데일리) · 치장 수익화(카드 스킨·합체 이펙트)는 v1 문서 계승
