# 스트라이크 (Strike) — 룰 정본 v1.0

> 2026-08-29 확정. 본편(스코어 포커)의 카드·족보·판정 위에 새 규칙을 얹은 실험 모드.
> 원소 실험(트라이 배틀 v1~v3)은 전부 폐기 — git 히스토리에만 남는다.
> 모든 수치는 시뮬(§6)로 검증. 시뮬: 세션 스크래치 `strike_sim.py`.

## 0. 한 줄 요약

매 턴 카드를 **비공개로 1장 뽑아** 내 3줄에 왼쪽부터 놓거나, 상대 필드의
**같은 숫자를 쳐낸다**. 칩으로 내 카드를 숨기고 상대 카드를 훔쳐본다.
정산은 본편 그대로 — **3줄 중 2줄을 이기면 승리.**

## 1. 구성

| 항목 | 값 |
|---|---|
| 덱 | 표준 52장 (조커는 v1.1 서랍 — 공격 매칭과 얽혀 보류) |
| 필드 | 각자 3줄 × 5칸, 각 줄은 **왼쪽부터 순서대로** 채운다 |
| 시작 | 손패 **4장**, 칩 **4개** (판당 고정, 보충 없음) |
| 턴 | 교대. 턴 시작에 덱에서 1장 **비공개 드로** — 손은 5장 유지 |

## 2. 턴 행동 (본 행동 1개 + 덤 행동)

- **배치**: 손패 1장을 내 줄의 다음 칸에. 앞면 무료 / **뒷면 = 칩 1**
  (뒷면 카드는 상대에게 안 보이고 **공격받지 않는다**)
- **공격(스트라이크)**: 손패의 랭크 = 상대 필드의 **보이는** 카드 랭크 → 지목.
  **두 장 모두 제거**(오른쪽 카드는 왼쪽으로 당겨짐), 공격자는 보충 1장을 뽑는데
  이것이 **방어막 카드**(§3)
- **버리기**: 내 필드가 만석일 때만 (공격은 의무가 아니다)
- 덤 행동(턴 소모 없음): **훔쳐보기 = 칩 1** — 상대 뒷면 1장을 나만 확인,
  이후 내가 공격할 수 있다. 훔쳐본 흔적(👁)은 양쪽 다 보인다

## 3. 방어막 카드 — 공격의 보상이자 무기

공격 보충 카드는 **공격 불가·피격 불가**(🛡). 대신 **양쪽 필드 아무 유효 칸**에
놓을 수 있다: 내 빈칸을 안전하게 채우거나, **상대 줄에 낮은 카드를 꽂아 족보를
방해**한다. 방어막이라 상대는 그것을 제거할 수 없다 — 시뮬에서 이 선택이
승률을 가장 크게 가르는 스킬 포인트다.

## 4. 종료·정산

양쪽 필드 완성 **또는 덱 소진** 시 전 카드 공개 → 본편 판정:
줄1↔줄1·줄2↔줄2·줄3↔줄3, **2줄 승 = 승리**, 2줄 미만이면 총점차, 같으면 무.

## 5. 확정 원칙

1. **족보·판정은 본편 그대로** — 새 룰은 "카드가 필드에 오는 방식"만 바꾼다.
2. **큰 족보는 공격 표적이다** — 페어를 앞면에 깔수록 노출된다. 지키려면 칩으로
   숨겨라. 족보 욕심 ↔ 칩 소모 ↔ 정보 노출이 한 고리.
3. **계산은 게임이 하고 플레이어는 비교만 한다** — 배치 칸 하이라이트, 공격 표적
   붉은 글로우, 줄 라벨 "페어→트리플" 미리보기가 UI 전제.
4. 연출은 본편 부품 재사용: flyCard 비행, poofCard 쳐내기, hitFlash/sparkBurst
   타격, shieldGlint 잠금, VeilChip 칩.

## 6. 시뮬레이션 근거 (52장 덱, 가치공격 봇 자가대전 300판/조건)

| 검증 항목 | 결과 |
|---|---|
| 공격 빈도 | 시작 패 0장 2.0회/판 → **4장 4.3회/판** (패가 곧 공격 기회 — 패 4 확정) |
| 시작 패 6장 | 공격 4.8회지만 **덱 소진 종료 55%** — 판이 미완성으로 끝나 탈락 |
| 덱 소진 종료 | 패 4 기준 17% (유효한 종료 — 본편 총점 판정 가능) |
| 판 길이 | 중앙값 34턴 (1인 17턴) |
| 칩 경제 | 뒷면 5~7회 + 훔쳐보기 1~3회 수요 > 칩 4 공급 — 항상 아쉽게 |
| 뒷면의 가치 | 공격 기회 차단 15~16회/판 |
| 방어막 판단 | (v3 시뮬 준용) 상황 판단형 71% vs 무조건 자기 필드 29% |

## 7. 튜닝 서랍

- 조커 2장 재투입 — 와일드가 공격 매칭·족보에 어떻게 얽힐지 규칙 필요
- 칩 5개 또는 "공격 성공 시 칩 +1" — 심리전 비중 레버
- 시작 패 5~6장 + 덱 2벌(104장) — 공격 빈도 상향이 필요하면
